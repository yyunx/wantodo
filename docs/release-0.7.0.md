# Wantodo 0.7.0

日期：2026-11-16

这一版把「便签板」拆成两个表面：**结构化**（原来的多栏待办卡）和**自由**（可以画、可以贴图、可以摆任意位置的画布）。两个表面共用一份数据、一个窗口、一套主题；切换只是换视图，不是换应用。

## 相对 0.6.0 的变化

### 主题：拆成「材质 × 色板」两个正交维度

- 旧的三字段（`theme` 一锅端、`formId`、`themeEffects`）废弃，换成 `themeId`（材质）+ `paletteId`（色板）。**色板只决定颜色，材质只决定圆角与透明度**，互不干扰。
- 色板沿用 7 套（Tokyo Night Day / Tokyo Night / Latte / Frappé / Macchiato / Mocha / Neon）；旧主题名自动映射：`dracula`/`catppuccin` → `mocha`，`cyber` → `neon`，`github-light`/`sakura`/`comic` → `light`，其余 → `dark`。
- 材质本期只有「液态玻璃」一个值。Win11 22621+ 用 Mica；Win11 22000–22620 用 `DWMWA_MICA_EFFECT`；更老的系统退纯色并在日志里留一条 WARN——**不会假装有玻璃**。
- 设置页「材质主题」下拉 + 画布状态行右端 **7 个色点**，点一下换色板。

### 两个表面

- 顶栏第一行左侧是**分段控件**：结构化 / 自由，旁边 `＋`（目前只弹「未实现」提示，0.8 之后才有第三表面）。
- 结构化表面保持 0.6.0 的用法：4 种卡（记事 / 待办 / 计时 / 图片）+ 栏选择 + 撤销。
- 自由表面：白色画布，可缩放 25%–400%（滚轮、`＋`/`−`、适应按钮），可平移（手形工具或 `空格 + 拖`）。
- 两个表面各自一条撤销栈，各 50 步，`Ctrl + Z` / `Ctrl + Y` 只作用于当前表面。

### 自由表面能干什么

- **十个工具**：选择 `V`、手形 `H`、文本 `T`、图片 `图`、矩形 `R`、线 `A`、箭头（无默认快捷键）、画笔 `B`、橡皮 `E`、缩放 `放`。互斥高亮。
- **笔迹**：一笔一个 `board\ink\<id>.isf`，模型里只存路径。超过 500 笔或 2000 顶点时把已有笔迹合成一张位图（静态化），新笔迹仍可继续画。
- **图形**：矩形 / 直线 / 箭头，拖动时先出虚线预览，太小（<8 px 或 <6 px）当误触丢弃。
- **文本**：点一下建文本框，双击进入编辑，`Enter` 提交、`Esc` 取消；空文本自动删掉。
- **图片**：只能活在自由表面。结构化表面点「图片」会自动切到自由表面再让你选文件；`Ctrl + V` 贴剪贴板位图或图片文件、拖图片文件进窗口也一样，都会自动切过去。
  - 资产按内容寻址：`board\canvas-images\<sha256 前 16 位>.<ext>`，同一张图贴两次目录里只有一个文件；`data.json` 里只有相对路径，**不含 base64**。
  - 单张上限 20 MB；总量超过 200 MB 会提示清理。

### 待办卡 = 栏目投影

画板上的待办卡不再复制一份条目，而是**投影**到某一栏：桌面上加一条，1 秒内出现在卡里；卡里勾选，桌面上同步划线。卡里也能直接加一条（回车）。

### 拖动与改名的分离

卡头按住移动超过 4 DIP 才开始拖动；改名只走**双击标题**或 `F2`。单击一百次也不会进编辑——这是 0.6.0 里“想拖却改名/想改名却拖走”的根因修复。

### 计时

- 状态机：`未开始 → 已设置 → 进行中 ⇄ 已暂停 → 已结束`，按钮依次是「开始 / 暂停 / 继续 / 重新开始」。
- 设置完**不会自动开始**，必须再点一次「开始」。
- 番茄钟支持分段（最多 4 段，每段 `重复数 / 专注 / 休息`），卡片上显示「第 N 组专注 · 剩余 mm:ss」，总进度走同一份时间轴；简洁版与自定义可互转（切回简洁版会二次确认）。

### 外观与交互细节

- 深色下系统的白色下拉/按钮/滚动条全部换掉：自绘 ComboBox、Button、TextBox、ScrollBar、ContextMenu/MenuItem。
- 两个表面都有空状态文案；画布与卡片都有右键菜单（新建/粘贴/改名/置顶/删除/全选）。
- 面板本身也接了液态玻璃（Win11 上桌面透出来）。

## 数据在哪

- 默认 `%LOCALAPPDATA%\Wantodo`，程序旁边有 `portable.txt` 时用 `<程序目录>\data`。设置页「数据目录」显示当前根。
- 0.7.0 首次启动会自动升级 `data.json` 到 v3：**先备份成 `data.json.pre-070.bak`**，再把旧 `canvas.json` 的内容并进 `data.json` 的 `canvas` 节点，旧文件改名 `canvas.imported-<时间戳>.json` 保留（不删）。
- 画布与便签板现在用**同一个** `data.json`（0.6.0 的独立 `canvas.json` 不再写入）。

```
<数据根>\
  board\data.json              便签板 + 画布（v3，原子写，data.bak 回退，损坏隔离）
  board\canvas-images\<hash>.<ext>   自由表面图片资产（内容寻址，自动去重）
  board\ink\<id>.isf           自由表面笔迹（一笔一个文件）
  board\blockers.md            卡住清单
  notes\inbox\*.md|txt         随心记
  trash\assets-<时间戳>\        启动时清理出来的孤儿图片/笔迹（可手动删）
  logs\app-yyyyMMdd.log
```

## 已知限制（都写进了 `docs/verify/0.7.0/progress.md`）

- **包体积超红线，且没有改红线**：FDD zip **285,331 B**，红线 229,376 B，超 **55,955 B**（0.6.0 基线 247,796 B 时就已超 18,420 B）；SC zip **63,957,693 B**，红线 63,900,000 B，超 **57,693 B**。本期只做了零成本减重（删掉零引用的取色器窗口，−2,739 B）。可行的下一步是拆 WPF 资源字典、删旧链接卡渲染路径，都还没做。
- **V-12 的三条数字没在真机测**（首帧 ≤1153 ms / private ≤105.1 MB / 50 卡 500 笔 ≥55 fps）：本机一直有一个实例在跑，单实例 Mutex 会让新实例立刻退出；复测命令写在 `p2.2.md` §4。
- **笔迹静态化在 CPU 软件光栅下反而更慢**（50 图元 + 500 笔：58 ms → 105 ms/帧）。它针对的是墨层命中与逐帧矢量重绘的 CPU 开销，真实合成器收益未验证。
- **Win10 的 Acrylic 降级只有代码路径和 WARN 文案**，没有真机。
- 主窗口还没有接材质（只有面板与设置页有）。
- 自由表面还没有背景网格、拖拽虚线指示、计时进度环（矩阵里标 ◐/✗ 的六项）。
- 图片资产 200 MB 的提示只有逻辑层测试。
- 待办投影每秒重建行，超过 50 条走「还有 N 条，去桌面上看」的截断，没做虚拟化。
