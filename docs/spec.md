# 产品规格 v0.1

## 一句话

一个贴在 Windows 桌面上的便签板：像手机主屏的小组件那样一直在，默认分两栏 ——
左边「要做的事情」，右边「突然想到的问题」。栏数可增减。

## 用户场景（这是验收的真正标准）

1. 开机后不用打开任何东西，它已经在桌面上，位置和上次一样。
2. 干活时按 Win+D 回到桌面，它还在；随便打开一个窗口，能被盖住（不聊工作的时候它不抢镜）。
3. 突然想到一个念头，鼠标点进右栏，打一行字，回车，念头就存下了 —— 全程不离开当前情绪。
4. 做完一件事，点一下勾，划掉，视线立刻离开。
5. 关掉电脑再开，所有内容、栏数、位置、外观设置原样回来。

## 功能分级

### P0（第一个可用版本必须有）
- 桌面层常驻窗口（默认 `Desktop` 模式），可拖动、可缩放、记住位置与尺寸
- 多栏布局（默认 2 栏，可增删栏、可改栏标题，范围 1–4）
- 条目：新增（回车提交、Esc 取消）、编辑、删除、勾选完成（删除线）、拖动排序
- 跨栏拖动条目
- 本地持久化 + 崩溃后可恢复（原子写 + bak）
- 无边框、无任务栏按钮、Win+D 后仍可见、Explorer 重启后自动重挂
- 托盘图标：显示/隐藏、切换层级模式、退出

### P1（可用之后立刻想要的）
- 完成项默认收起（可切换「划线保留 / 隐藏在完成区」）
- 栏数变化时布局自适应；窄窗口降级单栏
- 外观：浅色/深色/跟随系统，磨砂或纯色底 + 色调强度（**不是**窗口看穿桌面，原因见 decisions.md D3）
- 多显示器 + 高 DPI（PerMonitorV2）正确
- 全局快捷键：快速记一条（不弹主窗）

### P2（先不做，但设计时留口）
- 导出 Markdown / 明文
- 多个便签板（每个板位置独立）
- 富文本、链接可点、图片
- 云同步

## 非目标（明确不做）

- 不做跨平台（Windows-only 是产品设定，不是妥协）
- 不做账号、不做网络请求、不做遥测
- 不做多人协作
- 不接管系统便签、不替换 Windows Sticky Notes

## 数据模型

```jsonc
{
  "schemaVersion": 1,
  "window": {
    "left": 120, "top": 80, "width": 760, "height": 420,
    "mode": "Desktop",            // Desktop | Normal | Topmost
    "tone": 0.0,                  // 色调强度 0..1（背景明暗微调，不是窗口透明度）
    "theme": "System"             // System | Light | Dark
  },
  "columns": [
    { "id": "c_todo", "title": "要做的事情", "order": 0 },
    { "id": "c_idea", "title": "突然想到的问题", "order": 1 }
  ],
  "items": [
    {
      "id": "i_7f3a",
      "columnId": "c_todo",
      "text": "把 WorkerW 探针跑通",
      "completed": false,
      "order": 0,
      "createdAt": "2026-11-09T22:00:00+08:00",
      "updatedAt": "2026-11-09T22:00:00+08:00",
      "completedAt": null
    }
  ]
}
```

约定：
- `completed` 与「是否隐藏」是两个独立概念，绝不把状态编码进 `text`。
- `order` 是稀疏整数（步长 1024），插入时取中值，避免每次全量重排。
- 所有时间用 ISO 8601 带偏移；反序列化必须容忍字段缺失（向前兼容）。
- 写盘节流 300–500ms 合并；**关闭窗口与退出前必须强制落盘一次**。

## 交互细节（容易被做错的地方）

- 回车 = 提交并新建下一条（保持输入焦点在同一栏），不是「提交后失焦」。
- 勾选框的点击热区要够大；划线的动画短于 120ms。
- 拖动排序要有落点提示，不能是「松手后跳变」。
- 窗口拖拽只认标题空白区，不能和条目拖拽冲突。
- 缩放热区 6px，窗口最小尺寸要限制，否则两栏会挤爆。
- 失焦**不隐藏**窗口（它是桌面物件，不是弹窗）。
