# Wantodo 0.6.0

日期：2026-11-19

这一版把「便签板」拆成两个表面：**卡片式**（原来的多栏待办卡，卡可以拖、可以改大小）和**画布**（可以画、可以贴图、可以摆任意位置）。
两个表面共用一份数据、一个窗口、一套主题；切换只是换视图，不是换应用。

> 开发过程中这个里程碑的内部目录叫 `0.7.0`（`docs/plan-0.7.0.md`、`docs/verify/0.7.0/`），对外发布的版本号是 **0.6.0**。

## 相对 0.5.1 的变化

### 两个表面

- 顶栏第一行左侧是分段控件：**卡片式 / 画布**，旁边 `＋`（目前只弹「未实现」提示）。
- 卡片式：4 种卡（记事 / 待办 / 计时 / 图片）+ 栏目下拉 + 卡头拖动 + 右下角改大小。
- 画布：十个工具（选择 / 手形 / 文本 / 图片 / 矩形 / 线 / 箭头 / 画笔 / 橡皮 / 缩放），缩放 25%–400%，`空格 + 拖` 平移。
- 两个表面各自一条撤销栈，各 50 步，`Ctrl + Z` / `Ctrl + Y` 只作用于当前表面。

### 画布：笔、橡皮、图形

- 笔迹一笔一个 `board\ink\<id>.isf`，模型里只存路径；超过 500 笔或 2000 顶点时把已有笔迹合成一张位图，新笔迹仍可继续画。
- 笔和橡皮走画布自己的指针逻辑（不再依赖 InkCanvas 的输入模式），橡皮有 12 DIP 容差，按住可以连续擦。
- 切到笔 / 橡皮 / 放大镜时鼠标形状跟着变：画笔、橡皮、放大镜。
- 图形（矩形 / 线 / 箭头）拖动时就是最终样式，太小当误触丢弃。

### 工具栏：看得见的画笔颜色

- 「色」按钮上直接显示**当前画笔颜色**（`#CBA6F7` 这样）与粗细，点开是 8 种颜色 + 4 档粗细。
- 画笔颜色认准你挑的那个色：换主题、换背景都不会把已经选好的笔色悄悄改掉；想跟随色板就选「跟随色板强调色」。

### 主题

- 材质（液态玻璃）× 色板（7 套）两个正交维度；色板只决定颜色，材质只决定圆角与透明度。
- 状态行右端 7 个色点，**色点显示的就是那套色板的背景色**；点一下换色，卡片 / 图形 / 色点**立刻**跟着换。
- 默认深色（Tokyo Night 系列），设置里可切浅色。
- Win11 22621+ 用 Mica，老系统退纯色并写日志——不会假装有玻璃。

### 修掉的问题

- **画笔只有下半截能画**：`InkCanvas` 默认 `ClipToBounds=true`，负画布坐标的笔迹被整段裁掉；现在关掉自裁剪。顺带修掉「模型矩形被夹到 0」导致橡皮/框选命中错位，老数据启动时会自动按 ISF 外框自愈。
- **画完图形/一笔后点工具栏没反应**：给全局鼠标钩子那条路径补了捕获自愈、面板被别的窗口压住时自动提层，并在日志里留下 `[指针]` 证据链。
- **待办卡选栏目没反应**：捕获自愈把 ComboBox 自己的鼠标捕获当成泄漏清掉了，下拉一按下就关；现在只清理画板自己的捕获，并且刷新挪到下拉收起之后再排队执行。
- **颜色面板点不动**：同一个捕获自愈把 Popup 关了；现在认 Popup / 模态对话框 / ComboBox。
- 便携副本（带 `portable.txt`）不再被已安装版用单实例互斥顶掉。

## 已知限制

- 只有两个表面，`＋` 里的「日历 / 参考文件 / 图片库」还没实现。
- 画布的静态化笔迹是一张位图，静态化之后那部分不能再逐笔擦除（可以整块选中删除）。
- 没有代码签名，首次运行会被 SmartScreen 拦一下。
