# Wantodo 0.6.0

日期：2026-11-14

## 相对 0.5.1 的变化

- **主题形式感**：新增樱花、赛博、美漫三套主题（浅粉纸感 / 青蓝霓虹 / 米白漫画），在纯换色之外加描边、圆角与矢量纹理；设置页有「主题效果」开关，关掉回到纯色。显示名统一为「深色 / 浅色 / 樱花 / 赛博 / 美漫」。
- **下拉面板**：顶边把手可拖左/右/下边缘缩放，尺寸按工作区比例记忆；分隔条可见可拖，拖栏头可换位置（面板与桌面版共用同一份布局）。
- **随心记**：修掉保存后光标跳到文末；新建时先起名字，列表与状态栏显示真实文件名。
- 主题语法 `Theme` 新增 `Sakura / Cyber / Comic`；旧数据不用迁移。

## 数据在哪

- 默认 `%LOCALAPPDATA%\Wantodo`，若之前用 `portable.txt` 或设置过数据目录，则以那个为准（设置页「数据目录」一栏直接显示）。
- 迁移数据目录后需要重启一次。

## 已知限制

- 面板、设置窗、取色器与三个对话框还没有接主题形式感（描边/纹理只在主窗栏卡片）。
- 赛博的外发光、美漫的硬阴影只有参数，尚无视觉效果。
- 面板内「把条目拖到另一栏」尚未实现。
- 内存比 0.5.1 高约 8 MB（60 s 静置 private 100 MB），排查中。

## 两种包怎么选

| 包 | 大小 | 需要运行时 | 适合 |
|---|---|---|---|
| `wantodo-0.6.0-win-x64.zip` | 60.9 MB | 不需要 | 直接发给别人，解压双击即用 |
| `wantodo-0.6.0-fdd-win-x64.zip` | 0.2 MB | 需要 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) | 自己机器已经装了运行时，想省空间 |

> 本机更新开始菜单里的版本可用 `.\install.ps1 -Source 'publish\sc-0.6.0\Wantodo.exe'`（会覆盖 `%LOCALAPPDATA%\Programs\wantodo` 并重建快捷方式）。
