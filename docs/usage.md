# wantodo 使用说明

一块贴在桌面上的便签板：像手机主屏的小组件，默认两栏——「要做的事情」和「突然想到的问题」。
它待在桌面图标那一层：**普通窗口会盖住它，按 Win+D 它也不会消失，点桌面时它还在那儿**。

- 版本：0.4.0
- 系统要求：Windows 10 1809 及以上 / Windows 11（64 位）
- 不需要安装 .NET（用的是自包含单文件版本）

---

## 一、下载与安装

### 1. 拿到程序

目前没有公开下载站，程序在仓库的发布目录里：

```
E:\Dev\Project\wantodo\publish\sc\Wantodo.exe
```

如果这个文件不存在（比如新克隆的仓库），在仓库根目录执行一次发布（需要 .NET 10 SDK）：

```powershell
dotnet publish src\Wantodo.App\Wantodo.App.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish\sc
```

产物是**单个 exe（约 149 MB）**，不依赖机器上装没装 .NET，拷到哪都能跑。

### 2. 安装（推荐）

在仓库根目录右键「使用 PowerShell 运行」，或者：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

它做三件事，全部只在当前用户范围内，**不需要管理员**：

- 把程序复制到 `%LOCALAPPDATA%\Programs\wantodo\Wantodo.exe`
- 在开始菜单建一个 `wantodo` 快捷方式
- 加参数才有额外动作：`-DesktopShortcut` 建桌面快捷方式，`-StartWithWindows` 直接开开机自启

```powershell
.\install.ps1 -DesktopShortcut      # 顺便建桌面图标
.\install.ps1 -StartWithWindows     # 顺便开机自启
```

### 3. 不安装、直接用

也可以直接双击 `publish\sc\Wantodo.exe`，数据一样存在 `%APPDATA%\wantodo`。
缺点是没有快捷方式、不会跟着程序目录走。

### 4. 第一次运行时

- 会弹 SmartScreen「Windows 已保护你的电脑」——因为程序没有代码签名，点**更多信息 → 仍要运行**即可，之后不再提示。
- 第一次启动会自己出现在**主屏右上角**，并带几条示例内容，直接删掉即可。
- 托盘图标默认在任务栏右下角的**溢出区**（点 `^` 能看到，是一个深底蓝勾的图标）。想常驻：把它拖到任务栏上，或 设置 → 个性化 → 任务栏 → 其他系统托盘图标 里打开。

## 二、日常使用

### 加一条

在任意一栏底部的「＋ 添加一条，回车确认」处点一下，输入内容，按 **回车**。
加完会留在输入框里，可以继续敲下一条。

- **Shift + 回车**：条目内换行（一条里写两行）
- **Esc**：清空当前输入

### 勾掉一条

点条目前的**圆点**，或选中这一行按 **空格**。勾掉后：蓝底对勾 + 删除线 + 文字变灰。
再点一次取消。

### 改文字

**双击**条目 → 就地编辑 → 回车保存，Esc 放弃。编辑时：
- **回车** 提交
- **Shift + 回车** 换行
- **Esc** 取消

### 删除一条

鼠标移到条目行，右侧出现 **✕**，点它。

### 拖动排序

按住条目行拖动：拖到别的位置会出现一条**蓝色落点线**，松手即落位。
可以拖到同一栏的其它位置，也可以拖到另一栏。

### 键盘操作

| 按键 | 作用 |
|---|---|
| `Enter`（输入框里） | 加一条并保持焦点 |
| `Shift + Enter` | 条目内换行 |
| `Esc` | 取消输入 / 取消编辑 |
| `↑` / `↓` | 在条目之间移动焦点 |
| `空格` | 勾选 / 取消勾选当前行 |
| `Enter`（选中条目时） | 就地编辑 |

### 栏（分组）

- **加一栏**：点右上角的「＋ 栏」，新栏会插在**你当前操作的那一栏右边**，最多 4 栏。
- **改名**：双击栏标题，输入后回车。
- **删栏**：点栏标题右边的 ✕。**栏里还有条目时会先问一次**，确认才删。
- **太窄怎么办**：每栏最窄 190（DIP），窗口放不下会在底部出现横向滚动条，不会把字挤成一条缝。

### 快速记一条（不用切窗口）

按 **`Ctrl + Alt + Space`**，屏幕上方会弹出一个小输入框：

- 输入内容 → **回车**：记到「你当前正在操作的那一栏」（没有就记到第一栏）
- **Esc** 或点到别处：取消

### 托盘菜单

在托盘图标上**左键单击**：显示 / 隐藏这块便签（显示时不会抢走你正在打字的窗口）。

**右键**菜单：

- 显示 / 隐藏
- 设置…
- 层级：桌面层 / 普通窗口 / 置顶
- 外观：深色 / 浅色
- 隐藏已完成
- 开机自启
- 退出

> 隐藏窗口后，程序还在跑，`Ctrl+Alt+Space` 依然能用。

### 设置面板

托盘右键 →「设置…」：

| 项目 | 说明 |
|---|---|
| 层级 | **桌面层**（默认，贴在图标层、Win+D 不消失、普通窗口能盖住）/ **普通窗口**（和别的程序一样）/ **置顶**（盖在所有窗口上面，适合当强制提醒） |
| 外观 | 深色 / 浅色 |
| 色调强度 | 0 是纯基色，往右调背景会染上一点蓝色（文字颜色不变，不影响可读性） |
| 隐藏已完成的条目 | 勾上后已划线的条目从界面消失（**数据还在**，取消勾选就回来） |
| 开机自启 | 写当前用户的 `HKCU\...\Run`，关掉会删掉该值 |

改任何一项**立即生效**，不需要点保存。

## 三、数据、备份与恢复

### 数据在哪

```
%APPDATA%\wantodo\data.json      你的所有内容（可直接用记事本打开，中文可读）
%APPDATA%\wantodo\data.json.bak  上一次保存前的备份
%APPDATA%\wantodo\app.log        运行日志（排查问题时看这个）
```

在文件资源管理器地址栏输入 `%APPDATA%\wantodo` 即可打开。

备份时复制整个目录；恢复时**先退出程序**再覆盖回来。

### 保存机制

- 每次改动后约 **0.4 秒**自动保存（连续操作会合并，不会一直写盘）
- 关闭窗口、注销、关机前会强制保存一次
- 写盘是「先写临时文件 → 原子替换」，并留一份 `.bak`：断电或强杀进程最多丢最近 0.4 秒的输入，**不会写出半个坏文件**
- 如果主文件真的损坏了，启动时会自动回退 `.bak`；两个都坏才会把坏文件改名成 `data.corrupt-<时间>.json` 并起一个空白库

### 想从零开始

退出程序 → 删掉（或改名）`data.json` 和 `data.json.bak` → 重新启动，会得到默认两栏。

## 四、常见问题

**Q：它在哪？怎么被浏览器盖住了？**
桌面层模式下这是设计如此：它待在图标那一层，普通窗口覆盖上来就会盖住它。不想要这个行为，就在设置里换成「置顶」。

**Q：按 Win+D 桌面的时候它还在吗？**
在。桌面层模式不参与 Win+D 的最小化。实测过。

**Q：托盘图标找不到？**
Windows 11 默认把新图标放进溢出区（任务栏右下角的 `^` 里）。可以拖到任务栏常驻。

**Q：双击 exe 没反应 / 只闪了一下？**
程序是单实例的：如果已经有一个在跑，第二次双击只会把它叫到前面，不会开第二个窗口。看下托盘或按 `Ctrl+Alt+Space` 确认它还活着。

**Q：`Ctrl+Alt+Space` 没反应？**
可能被别的软件占了（这个组合很热门）。日志里会有 `注册全局快捷键失败` 之类的记录；换个键位目前需要改代码，暂时只能关掉占用它的程序。

**Q：勾上了开机自启，重启后没出现？**
先确认 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 里有没有 `Wantodo` 值，且路径指向现在的 exe。如果程序目录挪过位置，关掉再打开一次自启开关即可。

**Q：窗口跑到屏幕外了 / 换了显示器不见踪影？**
启动时会自动把它拉回主屏可见区域。也支持多显示器和不同缩放比例（每显示器 DPI）。

**Q：怎么才能让它一直显示在桌面，但不挡鼠标？**
目前不支持点击穿透——因为要能直接编辑。需要穿透属于另一个产品取舍，暂不做。

**Q：内存占用多少？**
常驻大约 70–80 MB 私有内存、130 MB 左右工作集；系统在内存紧张时会自动回收工作集。

## 五、卸载

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

会停掉进程、删开始菜单（和桌面）快捷方式、清开机自启、删程序目录，**默认保留你的便签数据**。

要连数据一起删：

```powershell
.\uninstall.ps1 -RemoveData
```
