### PENDING-HUMAN 判据

1. **设置页材质**：portable 副本启动 → 点「设置」→ 看窗口背景。判据：能隐约看到桌面壁纸的色块/明暗，而不是一块纯色；把窗口拖到深浅两种壁纸区域，背景应跟着变。截图 `p0.5-settings-glass.png`。
2. **关掉效果**：设置页取消勾选「效果」→ 设置页底色应变回不透明纯色（内容层 `ThemeGlassContentBrush` 退成不透明），下次打开仍未变透明。判据：不重启也不该出现「半透明浮在桌面上、字看不清」。
3. **12 DIP 收起条**：面板收起再展开 20 次。判据：不该出现整条闪白/闪黑；若闪，记下来并给出触发次数。
4. **Win10 真机**：日志里应有「材质：build … 没有文档化的窗口材质 API…」WARN，且窗口为纯色、无黑块。

## 本步刻意没做

- **面板主窗口不启用材质**：`TopPanelWindow` 贴桌面层、自己管拖拽/缩放/命中测试，材质透出后观感（尤其 12 DIP 条与圆角）必须人眼看过才能定；先只给验收指定的设置页启用。面板切换留到 P2.1，判据同 PENDING-HUMAN 1。
- **L2/L3 层的逐控件铺开**：只加了资源键与 L1 用法，控件级 `ThemeGlassControlBrush` 在 P2.1 随「控件 × 令牌矩阵」逐行落地。
- **Win10 Acrylic**（`SetWindowCompositionAttribute`）：未文档化 API，本轮无 Win10 真机，按 m00314 Q8 的「探针不通 → 降级并改名」处理为纯色 + WARN，不写进产品。
