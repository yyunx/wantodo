## 6. 本步刻意没做 / 未偿清单

- 主窗口（#1）不接材质：常规窗口无常驻需求，材质一旦透出桌面，主窗口的卡片对比度与 0.6.0 观感都要重审。
- 工具栏圆角 10（#4）、自由表面背景网格（#9）、计时进度环（#12）、令牌名取色（#15）、空状态引导按钮（#21）、拖拽虚线指示（#22）。
- 图片卡右键仍是「打开图片」（P1.3 起的既有手势），没有套右键菜单，避免和双击打开抢事件。
- 面板材质若在真机上出现「点不动 / 拖不动」的回归，回滚只需删掉 `GlassSurface.Prepare/TryApply` 两行（D33 写了改回成本）。
