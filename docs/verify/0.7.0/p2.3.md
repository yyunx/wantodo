## 7. 起床简报（≤15 行）

1. 12 步全部走完（P0.1–P2.3），分支 `feat/0.7.0`，10 个 commit，未 push。
2. 每步都绿：最终 `build -warnaserror` 0 警告 0 错误；`test` **437 通过 / 0 失败**；探针 **81 条 PASS**。

5. 自由表面：十工具、25%–400% 缩放、`空格+拖` 平移、笔迹/图形/文本、每面 50 步撤销。
6. 图片只活在自由表面，内容寻址去重；待办卡变成栏目投影；拖动与改名彻底分离；计时有状态机与分段番茄钟。

9. 明天第一件事：按 `p2.2.md` §4 退出旧实例、跑 portable 副本，把首帧/private 抄进 `progress.md`，再决定要不要为体积拆资源字典。
