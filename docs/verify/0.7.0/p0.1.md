## 改动

- 新增 `src/Wantodo.Core/CanvasObject.cs`：`CanvasSurfaces`（`structured` / `freeform`）、`CanvasObject`（图元：image/stroke/shape/text，4–20000 尺寸夹取）、`CanvasViewport`（`Zoom` 0.25–4.0、`OffsetX/Y`）。

- `src/Wantodo.Core/Board.cs`：`Version = BoardMigration.CurrentVersion`，新增 `Canvas` 属性。
- 新增 `src/Wantodo.Core/BoardMigration.cs`：`Upgrade()`（v2→v3，旧 `formId` 记 WARN 后只读保留）+ `CanvasLegacyImport.Import()`（`canvas.json` → `Canvas.Cards/Objects`，成功后改名 `canvas.imported-<ts>.json`）。
