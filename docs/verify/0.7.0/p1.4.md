## 5 本步刻意没做

- 待办卡超过 50 条只显示前 50 + 「去桌面上看」（性能护栏，滚动虚拟化留 P2.2）。
- 自由表面没有「改名」概念（文字图元走双击编辑，见 P1.2）。
- 番茄钟的「跨天/跨会话」不特殊处理：剩余时间由 `startedAt + elapsed` 推，时钟回拨会按当前时间重算（与 0.6.0 一致）。
