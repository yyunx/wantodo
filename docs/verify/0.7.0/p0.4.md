## 结构上的三个「同一份」

- **同一份文档**：两个宿主 `Attach` 的都是 `_viewModel.Model.Canvas`；切换不改数据，只改哪一面可见。
- **同一个窗口**：`TopPanelWindow` 一个句柄，`ApplySurface()` 只碰子元素的 `Visibility`，不做 `Hide()/Show()`，也没有第二个 `Window`。
- **同一套主题**：`FreeformBoard` 的颜色全部 `SetResourceReference` 到 `TextPrimary` / `TextMuted` / `BorderSubtle`，没有裸 hex。
