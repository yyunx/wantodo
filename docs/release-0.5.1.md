# wantodo 0.5.1 发布说明

发布日期：2026-11-14。Windows 10 1809+ / Windows 11（x64）。

0.5.0 与 0.6.0 之间的一个小版本：把 0.6.0 已经做完的部分先发出来用，重点修 0.5.0 里
「保存后光标跳到文末」的随笔问题和几处日常手感。

---

## 一、相对 0.5.0 的变化

- **随心记光标不再跳**：保存 0.5 秒后，光标和滚动位置保持在原处；只有切换条目时才落到合适位置。
  根因是文件监视器把程序自己的写盘当成外部修改，重新载入时把光标推到了文末。
- **新建先命名**：点「新建」先起名字，输入框下方实时预览磁盘文件名（`20261114-1930-买牛奶.md`）；
  留空仍可先用「未命名」，之后第一次改标题会同步文件名。列表悬停和状态栏能看到真实文件名。
- **五套开源主题**：GitHub 深色 / GitHub 浅色 / Dracula / Nord / Catppuccin Mocha；
  可跟随系统（读一次系统设置，改动后在设置里重选）。所有组合的正文、次要、弱化、强调块文字都按
  WCAG 对比度校验，不再出现白底白字。
- **自定义主题**：设置 → 外观 →「自定义…」，选背景色与强调色，其余颜色自动推导；
  取色器带色相条、S/V 方块、hex 输入和实时对比度读数。
- **顶边下拉面板（实验性，默认关）**：设置里打开后，鼠标在主屏顶部停留 0.2 秒出现把手，
  按住往下拖即可拉下一块与桌面同源的便签面板；`Esc`、点面板外或上拖收回；全屏视频/游戏时自动让路。

## 二、数据在哪

与 0.5.0 相同，数据根默认在非系统盘（如 `E:\Wantodo`），位置记在注册表
`HKCU\Software\wantodo` 的 `DataRoot`。0.5.0 的数据目录可以直接沿用，无需迁移。

## 三、已知限制

- 顶边下拉面板只响应主显示器；显示器切换、DPI 变化后不重新注册。
- 主题「跟随系统」只在启动/切换时读一次，系统换深浅色后要重选一次。
- 顶边面板仍属实验性：如遇拖动不跟手或误收回，可在设置里关掉，其余功能不受影响。
