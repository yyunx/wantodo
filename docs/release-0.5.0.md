# wantodo 0.5.0 发布说明

发布日期：2026-11-10。Windows 10 1809+ / Windows 11（x64）。

---

## 一、能做什么

一块贴在桌面图标层上的便签板，普通窗口可以盖住它，**按 Win+D 它也不消失**。

相对 0.4.0，0.5.0 新增：数据根外置（不落 C 盘）、随心记笔记库、停靠式自由布局、卡住清单、
窗口宽度随栏数自适应。

- **多栏待办**：1–4 栏，栏名随时改；勾选、就地编辑、拖动排序、跨栏拖动。
- **停靠式自由布局**：拖动栏顶部把手，可把一栏停到另一栏的左/右/上/下，也可两栏互换；
  分隔条单独调比例，窗口大小不变。
- **窗口宽度自适应**：宽度跟随栏数（2 栏 592 / 3 栏 880 / 4 栏 1168 DIP），手动拖过窗口后切换为固定宽度。
- **随心记**：独立的 Markdown 笔记库（`.md` / `.txt`），左侧列表 + 右侧编辑器；外部用别的编辑器改文件，
  打开着的笔记 0.5 秒内自动跟新。
- **卡住清单**：顶栏「⚠ 卡住」打开「想做 ⇄ 卡在什么地方」两列表格，直接写 `blockers.md`；
  主界面条目悬停可看卡住原因，也可以把条目直接拖进去。
- **数据根外置**：内容不落在 C 盘用户目录，默认放在非系统盘（如 `E:\Wantodo`），路径记在注册表里，可迁移。
- **常驻细节**：托盘图标、`Ctrl + Alt + Space` 快速记一条、开机自启开关（可回滚）、深浅两套外观、
  单实例、崩溃/强杀不写出半个坏文件。

## 二、数据在哪

数据根默认在**非系统盘**，例如：

```
E:\Wantodo\
  board\data.json        便签板内容（UTF-8，可直接用记事本打开）
  board\data.json.bak    上一次保存前的备份
  board\blockers.md      卡住清单（Markdown 表格，两列）
  notes\inbox\*.md       随心记笔记
  logs\app.log           运行日志
```

实际位置以注册表 `HKCU\Software\wantodo` 的 `DataRoot` 值为准；没有该值时回退到
`%LOCALAPPDATA%\wantodo\location.json` 记录的位置。在资源管理器地址栏输入该路径即可打开。

选址顺序：程序目录下有 `portable.txt` → 用程序目录下的 `data\`；否则看注册表指针；否则用非系统固定盘
（剩余空间大的优先，只写 `<盘>:\Wantodo` 这一层）；都不行才兜底到程序目录并记警告。

备份：退出程序后复制整个数据根。恢复：先退出程序，再覆盖回来。
迁移：设置 → 「迁移数据目录」，选新位置，程序复制并校验后提示重启；重启后新路径生效。
换机器：把数据根整个拷过去，启动后用同样的迁移入口指到新位置。

## 三、已知限制

- **没有代码签名**：首次运行会被 SmartScreen 拦，点「更多信息 → 仍要运行」。
- **自包含包体积大**：单文件约 149 MB（zip 60.9 MB），因为把 .NET 运行时一起打了进去。
- **文件名只改一次**：新建时定名，或「未命名」首次起标题时改名；此后改标题**不会**改文件名
  （文件名是外部链接与引用的锚点）。重名自动追加 `-2`。
- **卡住清单按文字匹配**：条目改名后不会自动同步 `blockers.md` 里那一行，需要手动改。
- **不支持点击穿透**：窗口要能直接编辑，所以鼠标点上去就是点它。
- **托盘图标默认在溢出区**：Windows 11 的行为，可拖到任务栏常驻。
- **`Ctrl + Alt + Space` 可能被别的软件占用**：被占时日志会记「注册全局快捷键失败」。
- **无自动更新**：升级就是下载新包覆盖 exe，数据不受影响。
- **安装脚本只写当前用户**：`%LOCALAPPDATA%\Programs\wantodo`，不碰系统目录，不需要管理员。

## 四、两种包怎么选

| | `wantodo-0.5.0-win-x64.zip` | `wantodo-0.5.0-fdd-win-x64.zip` |
|---|---|---|
| 大小 | 60.9 MB（exe 约 149 MB） | 0.2 MB（5 个文件，exe 约 524 KB） |
| 需要装 .NET 吗 | 不需要，解压双击即用 | 需要 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) |
| 适合 | 发给别人、换机器、不想管运行时 | 自己机器已装运行时，想省空间 |
| 启动 | 略慢（要先解包运行时） | 略快 |

用法都是：解压 → 双击 `Wantodo.exe`。想要开始菜单快捷方式，把 `install.ps1` 和 exe 放一起，
执行 `powershell -ExecutionPolicy Bypass -File .\install.ps1`。

卸载：`uninstall.ps1` 停进程、删快捷方式与自启、删程序目录，**默认保留数据**；
加 `-RemoveData` 才连数据一起删。
