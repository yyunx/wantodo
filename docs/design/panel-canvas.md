# 面板形态 B：自由画布设计（0.7.0）

> 状态：设计定稿，实现为 Phase 24。形态 A（树布局）继续保留，两者互斥切换。
> 本文只写「怎么做」；验收与预估见 `docs/plan.md` Phase 24。

## 1. 为什么不能复用 `LayoutNode`

| 维度 | `LayoutNode`（形态 A） | 画布（形态 B） |
|---|---|---|
| 位置 | 树 + 比例（`Ratio` 夹 0.15–0.85） | 绝对坐标 `X/Y`（DIP）+ 层级 `Z` |
| 尺寸 | 由父容器星号分配 | 每张卡片独立 `W/H` |
| 增删 | 插入/移除改变树形，兄弟自动重排 | 增删互不影响，其余卡片不动 |
| 拖拽语义 | 拖到目标栏的某侧 → 改结构 | 拖到任意位置 → 改坐标 |
| 并列 | 只能左右/上下二路切分 | 任意重叠、任意层叠 |
| 撤销 | 树的深拷贝即可 | 坐标/尺寸/层级/删除的混合栈 |

结论：两套模型并存。共用的是 `Note` / `NoteColumn` / `BoardViewModel` 与落盘通道，不是布局。

## 2. 数据模型

```json
// board/canvas.json（独立文件，不进 data.json）
{
  "version": 1,
  "items": [
    { "id": "c1", "kind": "note",  "x": 32,  "y": 48,  "w": 220, "h": 160, "z": 1, "style": "paper", "payload": { "noteId": "..." } },
    { "id": "c2", "kind": "todo",  "x": 280, "y": 40,  "w": 240, "h": 200, "z": 2, "style": "paper", "payload": { "columnId": "..." } },
    { "id": "c3", "kind": "timer", "x": 560, "y": 60,  "w": 160, "h": 120, "z": 3, "style": "paper", "payload": { "seconds": 1500 } },
    { "id": "c4", "kind": "link",  "x": 40,  "y": 240, "w": 260, "h": 90,  "z": 4, "style": "paper", "payload": { "url": "https://..." } },
    { "id": "c5", "kind": "image", "x": 340, "y": 260, "w": 240, "h": 180, "z": 5, "style": "paper", "payload": { "path": "..." } }
  ]
}
```

- `Board.PanelMode: "Dock" | "Canvas"`，默认 `Dock`；`canvas.json` 只在 Canvas 模式下读。
- 兼容：0.5.1 / 0.6.0 的 `data.json` 没有 `PanelMode` → 默认 Dock，不读 `canvas.json`。
- 回滚：`PanelMode` 改回 `Dock` 即完全回到形态 A；两份数据互不迁移、互不覆盖。

| 字段 | 类型 | 约束 |
|---|---|---|
| `id` | string | 前缀 `c` + 序号，文件内唯一 |
| `kind` | string | `note` / `todo` / `timer` / `link` / `image` |
| `x`、`y` | double | ≥0，超出画布时由视图夹到可见区 |
| `w`、`h` | double | 最小 140×90，最大 640×640 |
| `z` | int | 1–999；点击置顶时重排 |
| `style` | string | `paper`（0.7.0 只有这一种） |
| `payload` | object | 按 `kind` 解释；未知字段忽略 |

## 3. 交互流程

1. 顶部工具条 5 个图标 + 文字：记事 / 待办 / 计时 / 链接 / 图片。
2. 点工具 → 当前视口中心插入 220×160 卡片，`z` = 最大 +1，选中态 2 px 强调描边。
3. 拖卡片空白处 → 移动（8 DIP 网格吸附）；拖右下角 12×12 区域 → 缩放。
4. 重叠按 `z` 叠放；点击或拖动即置顶。
5. 删除：卡片右上角 ×，进 `trash/`；`Ctrl+Z` 撤销（20 步内存栈，不落盘）。
6. 形态切换：设置页「桌面版 / 下拉画板」二选一；只换窗口内容，不做数据迁移。

## 4. 视觉方案（默认选 A）

### A 纸片便签（采用）

```
┌────────────────────────────────────────────────────┐
│  [记] [待] [时] [链] [图]                 画布 100% │
│  ┌──────────────┐   ┌──────────────┐              │
│  │ 买牛奶        │   │ 交论文        │  ┌─────────┐ │
│  │ 2026-11-14   │   │ ☐ 初稿       │  │ 18:30   │ │
│  │              │   │ ☑ 图表       │  │ 计时    │ │
│  └──────────────┘   └──────────────┘  └─────────┘ │
└────────────────────────────────────────────────────┘
```

卡片底 `CardBackground`，1 px 描边，2 px 微投影，圆角 6；完成项 55% 透明 + 划线。

### B 卡片（备选，不采用）

```
╔══════════════════╗
║ ▣ 交论文          ║   ← 顶栏常驻标题 + 拖拽把手
╠══════════════════╣
║ ☐ 初稿            ║
║ ☑ 图表            ║
╚══════════════════╝
```

信息量高，但观感更「重」，且需要 hover 工具栏。

### C 便利贴网格（备选，不采用）

```
┌────┬────┬────┬────┐
│ 记 │ 待 │ 时 │ 链 │   ← 200×200 网格，自由拖动但自动对齐
├────┼────┼────┼────┤
│    │    │    │    │
└────┴────┴────┴────┘
```

整齐但失去「自由画布」的意义。

体积估计：三种都不含位图；单卡片模板 0.3–0.8 KB XAML；50 张卡片 `canvas.json` 约 12 KB。

## 5. 边界条件

| 项 | 决策 |
|---|---|
| 撤销/重做 | 20 步内存栈；重启清空 |
| 删除 | 进 `trash/`，可恢复；撤销优先于回收 |
| 重叠 | 允许；点击置顶；不做自动避让 |
| ≥50 卡片 | 拖动采样 ≥55 fps；超 100 张提示「可能变慢」 |
| 画布缩放（zoom） | 0.7.0 不做；坐标一律 DIP，留给未排期 |
| 多显示器 | 仍只主屏，与形态 A 一致 |
| 与外部文件的关系 | 记事卡片引用 `Note`，不在画布里存文本副本 |

## 实现补记（2026-11-15）：卡片内容做的四件事

设计初稿只画了「卡片 = 类型摘要」。实际落地时按用户要求补了四块，都在 `Controls/CanvasBoard.cs`：

1. **标题可改**：每张卡标题是透明 `TextBox`，默认显示类型名（记事/待办/图片/计时），
   输入写 `payload.title`，清空则回退类型名。标题栏仍然可以拖整张卡。
2. **链接内嵌**：不再有独立 `link` 类型（旧 `canvas.json` 里的 `link` 卡仍按原样显示 url）。
   记事与待办的正文由 `Core/TextLinks` 扫出 `http/https/www` 链接，列成按钮，点击用默认浏览器打开。
3. **图片**：三条入口——工具条「图片」选文件、资源管理器把文件拖到画板、`Ctrl+V` 粘贴剪贴板图片。
   图片一律复制进 `board/canvas-images/`，`payload.path` 只存文件名，原图被移走也不影响显示。
4. **计时**：`Core/CanvasClock` 只存「玩法 + 总秒数 + 开始时刻」，显示时按当前时间算，不把每秒剩余写盘。
   画面上的 `DispatcherTimer` 每秒刷新；到点写 `payload.fired=1`（只触发一次），右下角 `ToastWindow`
   提醒并 `SystemSounds.Exclamation` 响一声。四种玩法：正计时、倒计时、闹钟、番茄钟。

边界：计时只在程序运行时走；关掉程序不会补提醒（未排期）；卡片删除仍未进 `trash/`。
