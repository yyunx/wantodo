# 分阶段开发计划

## 工作方式（比计划本身更重要）

1. **一次只做一个阶段**。Codex 拿到的是一个阶段的完整任务，而不是「把 App 做出来」。
2. **每阶段先 Plan 后 Code**：让它先输出「改哪些文件、用什么 API、验收怎么测」，你点头再写代码。
3. **阶段门控**：验收项里有任何一条没通过，就不进入下一阶段，让它修。
4. **人是唯一的视觉验收者**：Win+D、拖拽手感、文字是否发虚，Codex 无法自查，必须你肉眼确认后回一句「通过」。
5. **要求它交证据**：每条验收对应一条命令或一个日志行，写进 `docs/verify/phaseN.md`。

## 阶段总览

| 阶段 | 主题 | 产出 | 风险 |
|---|---|---|---|
| 0 | 桌面层探针 | 能证明 WorkerW 在你机器上怎么工作 | **最高** |
| 1 | 骨架 + 两栏静态界面 | 能看、能存、能读 | 低 |
| 2 | 交互 | 能真正当便签用 | 中 |
| 3 | 健壮性（持久化/DPI/多显示器/Explorer 重启） | 敢长期挂着不丢数据 | 中高 |
| 4 | 托盘、设置、快捷键、主题 | 顺手 | 低 |
| 5 | 打包与实测 | 能装上、能报体积 | 低 |

## Phase 0 — 桌面层探针（最高风险，先做，1 个任务）

**目的**：在写任何产品 UI 之前，先证明「窗口能挂在桌面图标层，且 Win+D 后还在」在你机器上成立。
这一阶段写的是**一次性探针**，允许丑，允许全部放 `spike/`。

**任务内容**
1. 装 .NET 10 SDK 到用户目录（非管理员）：
   `dotnet-install.ps1 -Channel 10.0 -InstallDir "$env:LOCALAPPDATA\Microsoft\dotnet"`
   并确认 `dotnet --version` 走的是 10.x。
2. `spike/DesktopLayerProbe`：一个 700×200 的无边框窗口，内容只有一行大字 + 当前模式名。
3. 实现 `DesktopLayerService`，三种模式 + 全局热键 `Ctrl+Alt+1/2/3` 现场切换。
4. **拓扑探针**：枚举 `Progman` 及其子窗口，打印层级树（类名、标题、句柄、是否含
   `SHELLDLL_DefView`、`WorkerW` 个数）到 `%TEMP%\wantodo-probe.log`。
5. 发 `0x052C` 前后各打印一次拓扑，做对比。
6. 监听 `TaskbarCreated`，Explorer 重启后自动重挂，并记录耗时。

**验收（逐条打勾，写进 `docs/verify/phase0.md`）**
- [ ] `dotnet --version` 输出 10.x，且是用户目录里的 SDK
- [ ] 探针日志能清楚显示：`0x052C` 前后 WorkerW 数量的变化、`SHELLDLL_DefView` 的父窗口是谁
- [ ] `Ctrl+Alt+1` → 窗口位于桌面图标层：打开浏览器，浏览器盖住它
- [ ] 在该模式下按 **Win+D**：窗口仍然可见（这一条是项目生死线）
- [ ] `Ctrl+Alt+3` → 置顶，能盖住浏览器
- [ ] `Ctrl+Alt+2` → 普通窗口，出现在 Alt+Tab 里
- [ ] 任务管理器里结束 `explorer.exe` → 重启后 30 秒内自动回到桌面层
- [ ] 窗口拖动到 125% / 150% 缩放的第二块屏（如有）后文字不糊、位置正确（无第二屏则跳过并注明）
- [ ] `docs/verify/phase0.md` 记录：用了哪种 owner 方案、Win+D 是否被自动拦截、若无拦截做了什么补偿

**如果 Win+D 这条挂了**：不要绕过去继续写产品，先在小范围里试三种补偿（拦
`WM_WINDOWPOSCHANGING` 的 `SWP_HIDEWINDOW` / 收到 `WM_SYSCOMMAND` 后
`ShowWindow(SW_SHOWNOACTIVATE)` / 注册为 `WS_EX_TOOLWINDOW` 且 owner 为 `Progman`），
把各自结果写进 `docs/verify/phase0.md`，选一个，再往下走。

## Phase 1 — 骨架 + 两栏界面（1 个任务）

- 建解决方案：`src/Wantodo.Core`（无 WPF 依赖，可单测）、`src/Wantodo.App`、`tests/`
- `Wantodo.Core`：模型 + JSON 仓储（原子写 + bak 回退 + 损坏隔离），**先写单测**
- `Wantodo.App`：无边框窗口、两栏 `UniformGrid`、绑定数据、加载即显示
- 从 Phase 0 的探针里搬逻辑进 `Interop/`，删掉 spike 里的重复实现

**验收**
- [ ] `dotnet test` 通过，覆盖：首次无文件、正常读写、损坏文件回退 bak、字段缺失兼容
- [ ] 启动后看到两栏 + 预设条目，位置尺寸来自 `data.json`
- [ ] 手动改 `data.json` 里某栏标题，重启后 UI 跟着变（证明是数据驱动，不是硬编码）
- [ ] 全窗口无 `AllowsTransparency="True"`（grep 证明）

## Phase 2 — 交互（1–2 个任务）

- 新增（回车提交并保持焦点）、编辑（双击/直接输入）、删除（Backspace 或右键菜单）、勾选划线
- 拖动排序 + 跨栏拖动，带落点指示
- 栏操作：加栏、删栏（含条目确认）、改标题
- 键盘流：`↑/↓` 在条目间移动、`Enter` 编辑、`Space` 勾选、`Ctrl+Enter` 换行

**验收**
- [ ] 连续敲 10 条待办不离开键盘、不失焦、不丢字
- [ ] 勾选后划线出现，重启后仍是划线态
- [ ] 拖到另一栏后重启，条目还在新栏
- [ ] 加第 3 栏、删第 2 栏后，布局与数据一致；删栏时有「里面的 3 条会一起删」的确认

---

## Phase 3 — 健壮性（1–2 个任务）

- 写盘节流 + 退出强制落盘；异常终止后重启内容完好（可用「任务管理器结束进程」验证）
- 多显示器 / 删除显示器后窗口不能跑到屏幕外（启动时做可见性纠正）
- DPI 变化（把窗口拖到不同缩放屏）后布局正确
- Explorer 重启、显示器休眠唤醒、锁屏解锁后的窗口层级保持
- 启动耗时与常驻内存记录（`dotnet-counters` 或任务管理器），写进 `docs/verify/phase3.md`

**验收**
- [ ] 编辑内容后在 1 秒内强杀进程 → 重启后内容还在（或至多丢最后 1 次编辑），不出现空库
- [ ] 拔掉副屏后重启，窗口自动回到主屏可见区
- [ ] 锁屏 10 分钟后解锁，窗口仍在桌面层
- [ ] 常驻内存（工作集）记录在案，目标 ≤ 80 MB

---

## Phase 4 — 托盘 / 设置 / 快捷键（1 个任务）

- 托盘：左键显示隐藏、右键菜单（层级模式、栏数、主题、开机自启、退出）
- 设置面板：栏数、主题、透明度、完成项处理方式、是否自启
- 全局快捷键「快速记一条」：小输入框贴屏幕边缘，回车入库后消失
- 开机自启走 `HKCU\...\Run`，默认关，开关要能真正回滚

**验收**
- [ ] 隐藏后托盘左键能召回，且不夺焦点
- [ ] 切换层级模式立即生效并写入配置
- [ ] 自启开关打开 → 注销重进后自动出现；关掉 → 不再出现
- [ ] 快速记一条：`Ctrl+Alt+Space` 唤出 → 输入 → 回车 → 30 秒内主窗能看到这一条

---

## Phase 5 — 打包（1 个任务）

- `dotnet publish -c Release -r win-x64`：先出 framework-dependent，再出 self-contained 单文件，两者都测体积
- 程序图标、窗口图标、版本号、单实例互斥（`Mutex`，二次启动唤出已有窗口）
- 提供 `install.ps1` / `uninstall.ps1`（复制到 `%LOCALAPPDATA%\Programs\wantodo`，建快捷方式，不写系统级路径）

**验收**
- [ ] 干净目录下双击能启动，不报缺运行时
- [ ] 报告两种发布模式的 exe 体积与启动耗时
- [ ] 重复双击不会开出两个窗口，只会把已有窗口提到前台

## 全局风险表

| 风险 | 触发条件 | 应对 |
|---|---|---|
| WorkerW 机制变动 | Windows 功能更新 | 探针化 + 三档降级 + 日志可诊断 |
| Win+D 隐藏窗口 | Shell 行为 | Phase 0 必须解决，不许带病往下 |
| 透明窗口软件渲染 | 用了 `AllowsTransparency` | 明令禁止（见 decisions.md D3） |
| 数据丢失 | 非原子写 / 退出不落盘 | 原子写 + bak + 强杀测试 |
| 多显示器/DPI | 换显示器、缩放不同 | 启动时可见性纠正 + PerMonitorV2 |
| Codex 幻觉 API | 让它「记得」Win32 用法 | 要求它先查文档并在 `docs/verify` 贴出处；编译不过就改，不许注释掉 |
